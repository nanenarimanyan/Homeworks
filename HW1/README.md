# Eco-Indigo Bass Model homework

Complete submission package for DS 223.

- `report/report.pdf is the final report
- `analysis.py`: Bass parameter estimation and forecasting
- `data/sustainable_cotton.csv`: OECD-FAO Table 10.1 historical data
- `data/proxy_fit.csv`, `data/forecast.csv`, `data/sensitivity.csv`: calculated results
- `img/`: generated figures
- `references/references.md`: source links

Run: `pip install -r requirements.txt && python analysis.py`
